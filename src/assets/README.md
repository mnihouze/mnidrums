# Assets folder

Drop your real files here to replace the placeholders referenced in the components:

- `musics/` — PDF sheet music (referenced from `pages/musics/musics.component.ts`)
- `lessons/` — PDF + PNG pairs (referenced from `pages/lessons/lessons.component.ts`)
- `books/` — PDF + PNG pairs (referenced from `pages/books/books.component.ts`)

If an image is missing, the file card automatically falls back to a simple document icon,
so you can add files gradually without breaking the layout.
